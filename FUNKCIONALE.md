# Rize — функциональная спецификация

## Концепция

Личный геймифицированный трекер задач и привычек. Петля мотивации: **галочка → +XP → цифра и стрик растут → график вверх → не хочешь ломать серию → возвращаешься завтра.**

Три якоря удержания пользователя: стрик, Productivity Score, график.

---

## Типы задач

| Тип     | Описание                                                         |
| ------- | ---------------------------------------------------------------- |
| `once`  | Разовая задача с опциональным dueDate                            |
| `daily` | Ежедневка по расписанию (пн/ср/пт или everyday)                  |
| `habit` | Привычка, может быть негативной (isNegative=true — её НЕ делать) |

Приоритеты: P1 (25 XP) / P2 (20 XP) / P3 (15 XP) / P4 (10 XP).
Категории: работа / спорт / учёба / личное / свои.

---

## Модель данных

```
users/{uid}
  totalXP, level, currentStreak, longestStreak, lastActiveDate, gold

tasks/{taskId}
  title, category, type, isNegative, priority, schedule[], dueDate, done, doneAt

logs/{logId}               ← единственный источник правды для статистики
  taskId, date (YYYY-MM-DD), type, xp, onTime

goals/{goalId}             ← v2
  title, target, progress, deadline, linkedTaskIds[]
```

> **Правило:** статистику считать ТОЛЬКО по `logs`. Никогда по `tasks`.

---

## Формулы

```ts
// XP за выполнение
xpForCompletion(task, onTime):
  base = { P1:25, P2:20, P3:15, P4:10 }
  if isNegative → return -base        // сорвался = минус
  return onTime ? base : base * 0.5   // просрочка = половина

// Штраф за пропущенную daily (раз в сутки при входе)
penaltyForMissedDaily(task):
  return -base * 0.6

// Уровень из XP
levelFromXP(totalXP):
  return floor(sqrt(totalXP / 50))
  // 50XP=1, 200=2, 450=3, 800=4 ...

// Productivity Score за период = sum(xp) из logs за период
// Может быть отрицательным — это намеренно, показывает провал
```

---

## Стрик

При выполнении хотя бы 1 задачи за день:

- `lastActiveDate == вчера` → `currentStreak++`
- `lastActiveDate == сегодня` → без изменений
- иначе → `currentStreak = 1` (серия сброшена)
- `longestStreak = max(longestStreak, currentStreak)`
- `lastActiveDate = сегодня`

---

## Что происходит при нажатии галочки

Транзакция Firestore:

1. `task.done = true`, `task.doneAt = now`
2. Создать запись в `logs` с `xp`, `onTime`, `date`
3. `user.totalXP += xp`
4. `user.level = levelFromXP(totalXP)`
5. Пересчитать стрик по правилам выше

---

## Что происходит при первом входе в новый день

1. Найти все `daily` задачи которые должны были быть вчера и не выполнены
2. Начислить штраф в `logs` за каждую (xp = отрицательный)
3. Пересчитать стрик — если вчера не было ни одного выполнения → `currentStreak = 0`

---

## График продуктивности (главная фича)

Переключатель: **День / Неделя / Месяц**

Агрегация из `logs`:

```ts
chartData = каждый день периода → {
  date,
  completed: количество logs за день,   // столбики (Bar)
  score: sum(xp) за день                // линия (Line), может < 0
}
```

Компоненты графика:

- `Bar` — количество выполненных задач (ось Y левая)
- `Line` — Productivity Score (ось Y правая, может уходить вниз)
- `Line` пунктир — прошлый период для сравнения
- Тренд: `±% vs прошлый период`

KPI над графиком: выполнено задач / стрик / средний score / лучший день

> Score **должен падать** в плохие дни. Это намеренно — провал мотивирует вернуться.

## Экраны

**1. Home / Dashboard**

- Большая цифра Productivity Score + тренд ↑↓
- Уровень + XP прогресс-бар + стрик + золото
- Главный график (переключатель День/Неделя/Месяц)
- Список задач на сегодня с галочками
- Предупреждение «не сломай серию» если день заканчивается

**2. Задачи**

- Список всех задач сгруппированных по категориям
- Фильтр: All / Once / Daily / Habit
- Приоритеты P1–P4 видны на каждой карточке
- Быстрое добавление: поле + тип + категория + приоритет + расписание

**3. Привычки**

- Сетка 2 колонки, каждая карточка = одна привычка
- На карточке: стрик, 7 точек последних дней (выполнено/пропущено)
- Негативные привычки помечены отдельно
- Лимит ~12 привычек

**4. Статистика**

- Расширенный график с переключателем периода
- Сравнение с прошлым периодом (пунктир)
- Completion rate по категориям (горизонтальные бары)
- Лучший / худший день
- Достижения / бейджи

**5. Календарь**

- Полный месяц (сетка 7×5)
- В каждой клетке: 2–3 первые задачи дня (обрезанные) + «•••» если больше
- Тап на клетку → bottom sheet со всеми задачами дня + XP за день
- Цвет клетки: зелёный тинт = продуктивный день, красный = провал

**6. Профиль**

- Уровень + XP прогресс-бар до следующего
- Стата: всего задач / лучший стрик / золото / completion rate
- Достижения (заблокированные серые / разблокированные gold)
- Раздел наград за золото (v2)

**7. Онбординг / Логин**

- Google / Apple / анонимный вход
- Данные привязаны к uid, видны только пользователю
