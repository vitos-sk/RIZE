# Kaizn — промты для генерации UI-макетов

> Как использовать: сначала прочитай "Общий дизайн-код" — это база, которая должна
> присутствовать в КАЖДОМ промте (я уже вставил её в каждый пункт ниже, так что можно
> копировать промты по одному прямо в чат с генерацией картинок). Каждый промт = один
> экран = одна картинка. Отправляй по одному за раз, не смешивай.

---

## 0. Общий дизайн-код (для консистентности между картинками)

Используется как основа во всех промтах ниже, чтобы все экраны выглядели как один продукт:

- **Платформа**: мобильное приложение (iOS-style), экран 375×812pt, safe area сверху и снизу.
- **Тема**: тёмная. Фон почти чёрный `#0B0B0F`, карточки `#17171C`, разделители `#26262E`.
- **Акцент**: золото `#D4AF37` (для чисел, прогресса, иконок успеха, свечения). Второй акцент —
  приглушённый изумруд `#3ECF8E` для позитивных изменений, приглушённый красный `#E5484D`
  для просрочки/срыва привычки.
- **Типографика**: крупные жирные цифры (гротеск, вроде Space Grotesk / SF Pro Rounded) для
  KPI-цифр; обычный текст — Inter/SF Pro, среднего веса, хорошо читаемый на тёмном фоне.
- **Компоненты стиля**: круглые чекбоксы с золотым свечением при выполнении; карточки задач
  с цветной вертикальной полоской приоритета слева (P1 — красная, P2 — оранжевая, P3 — жёлтая,
  P4 — серая); иконка огонька 🔥 для стрика; нижний таб-бар из 5 иконок (Главная, Задачи,
  Привычки, Статистика, Профиль) с золотой подсветкой активной вкладки.
- **Общее настроение**: дорого, минималистично, немного "геймифицировано", но БЕЗ RPG-мусора
  (никаких мечей/эльфов/аватаров-монстров) — ближе к Todoist/Linear/Things 3, чем к Habitica.
- **Формат вывода**: реалистичный UI-мокап приложения (как скриншот готового iOS-приложения),
  высокая детализация, чёткая сетка, ровные отступы, без искажённого текста где возможно —
  если текст будет нечитаемым, оставь плейсхолдер-цифры/короткие слова вместо длинных фраз.

## Как передать это в другой чат

1. Скопируй раздел **0** только один раз себе в заметки — не отправляй его отдельно,
   он уже "растворён" в каждом промте ниже.
2. Отправляй промты **1–8** по одному сообщению за раз, дожидаясь картинки перед
   следующим — так стиль не "поплывёт" между экранами.
3. Если модель для генерации картинок поддерживает референс-изображение — после первой
   удачной картинки (например, Dashboard) прикладывай её как референс к следующим
   промтам с фразой "выполни в точно таком же визуальном стиле" — это сильно повышает
   консистентность между экранами больше, чем текстовое описание.
